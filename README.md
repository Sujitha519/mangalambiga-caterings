- Deep Maroon #8C1428
- Burnt Orange #E66A0A

- Menu — interactive CSS flipbook with subtle Web Audio page-turn effect

- Blog

## Run
Open `index.html` in a browser. For the smoothest local experience, use VS Code Live Server or any simple static server.

## Enquiry form
The form is front-end only and opens the visitor's email client using a `mailto:` action. For production, connect it to a backend/email service.

## Images
Food/event imagery uses remote Unsplash image URLs so the website stays lightweight. Internet access is required for those remote images and the Google Fonts import.
